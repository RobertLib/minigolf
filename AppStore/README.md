# App Store metadata

The App Store Connect texts, kept in the project. Nothing is uploaded
automatically — open the file, copy the contents, paste it into the matching
field in App Store Connect.

The folders are named after the fastlane convention (`cs`, `en-US`), so if you
ever decide to move to `fastlane deliver`, renaming `AppStore/` to
`fastlane/metadata/` is all it takes.

## Where everything goes

App Store Connect → **Apps → Minigolf → iOS App → 1.0 Prepare for Submission**.
There is a language switch at the top (**Czech** / **English (U.S.)**) — every
field is filled in separately for each language.

| Field in App Store Connect | File | Limit | Currently |
|---|---|---|---|
| App Name | `<language>/name.txt` | 30 characters | 22 |
| Subtitle | `<language>/subtitle.txt` | 30 characters | 29 / 28 |
| Promotional Text | `<language>/promotional_text.txt` | 170 characters | 130 / 124 |
| Description | `<language>/description.txt` | 4000 characters | ~2030 |
| Keywords | `<language>/keywords.txt` | 100 characters | 92 / 91 |
| What's New in This Version | `<language>/release_notes.txt` | 4000 characters | 260 / 248 |
| App Preview and Screenshots | generated by the scripts, see [screenshots.md](screenshots.md) | 3–10 images | 8 + video |

Alternative names, subtitles and keyword sets (in case the name is taken or you
want to try different ASO) are in [alternatives.md](alternatives.md).

Checking the limits:

```bash
python3 - <<'PY'
import os
lim={'name.txt':30,'subtitle.txt':30,'keywords.txt':100,
     'promotional_text.txt':170,'description.txt':4000,'release_notes.txt':4000}
for loc in ('cs','en-US'):
    for f,m in lim.items():
        n=len(open(os.path.join('AppStore',loc,f)).read().rstrip('\n'))
        print(f'{loc:6}{f:22}{n:5}/{m}', 'OK' if n<=m else 'OVER!')
PY
```

## Notes on the individual fields

- **App Name** — has to be globally unique. Plain "Minigolf" is almost certainly
  taken, hence `Minigolf 3D: 108 Holes`. On the home screen the app stays just
  "Minigolf" (`INFOPLIST_KEY_CFBundleDisplayName`), which is fine and Apple does
  not mind — the home screen name only must not differ in *meaning*.
- **Keywords** — separate with commas and **no spaces** (a space counts towards
  the limit). Do not repeat words already in the name or subtitle, Apple indexes
  those separately; that is why "minigolf", "3D" and "holes" are missing from the
  list.
- **Promotional Text** — the only field that can be changed without a new build
  and without review. Useful for seasonal or topical messages.
- **What's New** — for a first release the field often does not appear at all; if
  App Store Connect does not offer it, skip it and use it from version 1.1 on.

## Settings that are not filled in with text

**App Information** (shared across all languages):

- Primary Category: **Games → Sports**
  (matches `LSApplicationCategoryType = public.app-category.sports-games`)
- Secondary Category: **Games → Casual**
- Content Rights: contains no third-party content
- Age Rating: **4+** — everything in the questionnaire is "None". Watch out for
  *Contests* and *Unrestricted Web Access* → both No. The game has no violence,
  no chat and no links out.

**Pricing and Availability:** Free, all countries.

**App Privacy:** click *Get Started* → **"No, we do not collect data from this app"**.
The game has no networking code, no third-party SDKs, and stores everything in
UserDefaults on the device (declared in `Minigolf/Resources/PrivacyInfo.xcprivacy`,
reason CA92.1). A **privacy policy URL is still mandatory** — the text is ready
in [privacy-policy/](privacy-policy/), it just needs hosting somewhere (GitHub
Pages, a gist, your own site) and the URL pasted into the *Privacy Policy URL*
field.

**Support URL:** a mandatory field. The project's GitHub page or a simple page
with an e-mail address will do.

**Marketing URL:** optional, feel free to leave it empty.

**Encryption:** `ITSAppUsesNonExemptEncryption = NO` is set in the project, so the
export compliance question never appears when the build is uploaded.

**App Review Information** → the note for the reviewer is in [review-notes.txt](review-notes.txt).
The game needs neither an account nor a demo login — leave *Sign-in required*
switched off.

## Release procedure

1. Xcode → Signing & Capabilities, check team `K6GM85X5D7`, bundle ID `cz.rob.Minigolf`.
2. App Store Connect → **Apps → +** → new record, bundle ID `cz.rob.Minigolf`,
   primary language **Czech** (or English, depending on which should be the
   fallback for unknown locales — **English (U.S.)** is the recommendation, for
   reach), SKU e.g. `minigolf-001`.
3. Add the second localisation (App Information → language switch, top right).
4. Fill in the texts from this directory. The screenshots and App Preview are not
   in the repo — build them with `Tools/appstore_media.sh` and upload them, see
   [screenshots.md](screenshots.md) for details.
5. Xcode → Product → Archive → Distribute App → App Store Connect → Upload.
6. Wait for the build to process (10–60 min), then select it in the *Build* section.
7. Fill in App Privacy, Age Rating, Pricing.
8. **Add for Review** → *Submit*.
